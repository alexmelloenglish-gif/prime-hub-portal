# PRIME Digital Hub — Student Learning Portfolio Presentation Contract v1.1

**Status:** FROZEN  
**Effective date:** 18 September 2026  
**Role:** Compatibility freeze / hierarchy correction  
**Supersedes:** `STUDENT-LEARNING-PORTFOLIO-PRESENTATION-CONTRACT-V1_2026-09-18.md` where that file conflicts with the official canonical template.

## 1. Canonical hierarchy

The official outer Portfolio structure was already frozen before this addendum and remains authoritative:

- GitHub: `docs/student-learning-portfolio-template-v1.0.md`
- Google Docs master: `Prime Digital Hub | Student Learning Portfolio Template`
- Master document ID: `1aBafqFhgwnSa0i29uPN3vg-uFv5gNeRIDg--4Aj3H-g`

The canonical template v1.0 MUST remain the outer structure for future Student Learning Portfolios.

This v1.1 contract does **not** replace or reorder that template.

The Portfolio keeps the v1.0 canonical order:

6. Learning Patterns

13. Current Goals
14. Vocabulary Bank
15. Grammar & Accuracy Overview
16. Teacher Feedback & Growth Priorities
17. Class Reports
18. Recommended Next Steps
19. PRIME DIGITAL HUB footer

Internal Teacher Validation / authoring-control sections in the master MUST be removed from the released student/family-facing copy.

## 3. Family / minor metadata

For a minor learner or Family Edition Portfolio, **Responsible / Responsável** is a required student-specific metadata field inside **Your Learning Snapshot**.

It identifies the responsible adult/contact role and does not replace learner identity.

## 4. Class Report v1.0 is additive

`CLASS-REPORT-PRESENTATION-CONTRACT-V1_2026-09-18.md` remains frozen and authoritative for the **internal structure of every completed Class Report**.

Therefore Section 17 of the canonical Portfolio template is expanded, not replaced.

Every persisted attended lesson must include:
1. Class Identity
2. What We Worked On
3. Learning Evidence / What We Noticed
4. Priority Corrections
5. Vocabulary Bank — This Lesson
6. Grammar Review — This Lesson
7. Support / Independence Level
8. Teacher Feedback / Current Priority
9. Recommended Next Steps
10. Evidence Boundaries

Mandatory empty-state rules remain in force. A required block may truthfully contain no persisted item, but it may not silently disappear.

## 5. Cumulative memory

The existing canonical Portfolio sections remain the cumulative longitudinal views:

- Vocabulary Bank
- Grammar & Accuracy Overview
- Teacher Feedback & Growth Priorities
- Attendance & Class History
- Current Goals
- Class Reports
- Learning Memory & Next Cycle

Lesson-level contributions feed these cumulative sections only when supported by evidence and teacher-authorized persistence.

## 6. Family Executive Summary

A short Family Executive Summary may be delivered as a **separate companion document or message**.

It is useful for WhatsApp / parent communication but is **not a new mandatory section inside the canonical Portfolio**, because the outer Portfolio structure is already frozen by template v1.0.

## 7. Frozen compatibility decision

> The PRIME Student Learning Portfolio Template v1.0 remains the single canonical outer Portfolio template. The Class Report Presentation Contract v1.0 strengthens Section 17 inside that template. It does not authorize a second competing Portfolio layout.

No future regeneration may silently replace the official canonical outer structure with a different section order.
