# PRIME Digital Hub — Frozen Student Learning Portfolio Presentation Contract v1.0

**Status:** FROZEN  
**Effective date:** 18 September 2026  
**Scope:** Family/student-facing longitudinal Student Learning Portfolio  
**Depends on:** Class Report Presentation Contract v1.0

## 1. Portfolio purpose

The Portfolio is the durable learner-facing longitudinal projection of verified learning memory. It must explain the learner's current state, show evidence-backed development across lessons, preserve useful history, and make the next teaching cycle clear.

It is not a transcript archive, internal teacher console, or runtime/database view.

## 2. Non-negotiable visible structure

Every canonical Family Edition Portfolio MUST render the following sections in this order:

1. **Portfolio Identity / Cover**
2. **Family Executive Summary**
3. **Learning Snapshot**
4. **Current Learning State**
5. **Strengths & Evidence**
6. **Learning Patterns**
7. **Current Pedagogical Priorities**
8. **Attendance & Class History**
9. **Cumulative Vocabulary Bank**
10. **Cumulative Grammar & Accuracy Overview**
11. **Teacher Feedback & Growth Priorities**
12. **Class Reports — complete longitudinal history**
13. **Next Learning Cycle / Recommended Next Steps**
14. **Family Guide / Evidence Boundaries**
15. **Quick Access / Learning Links**

A required section may state that evidence is unavailable. It may not silently disappear.

## 3. Family Executive Summary

The Family Executive Summary is mandatory in Family Edition portfolios.

It must answer in plain language:
- how many attended lessons are represented;
- what the learner has been working on;
- what has changed across the represented period;
- what remains developing;
- the current priority;
- the next cycle.

It must fit within a concise first-read section and must not require the family to read all individual Class Reports to understand the current picture.

## 4. Current vs longitudinal memory

The Portfolio must separate:
- **current learning state** — what should guide the next lesson;
- **longitudinal memory** — useful historical evidence, vocabulary, grammar, corrections and class reports.

A new lesson may refine current priorities. It must not erase valid earlier memory.

## 5. Class Reports

Every attended persisted lesson MUST have one complete Class Report compliant with **Class Report Presentation Contract v1.0**.

The Portfolio projection is NON-COMPLIANT if any persisted attended lesson lacks any required Class Report block.

## 6. Cumulative banks

### Vocabulary Bank
The cumulative bank is curated from lesson-level vocabulary contributions. It must retain useful reusable language without becoming a raw word dump.

### Grammar & Accuracy
The cumulative grammar view is curated from lesson-level grammar reviews and priority corrections. It must distinguish developing use from independent stable performance.

### Corrections
High-value recurring corrections may be surfaced cumulatively, but the original lesson-level correction remains in its Class Report for lineage.

## 7. Evidence and level safety

- No automatic CEFR advancement.
- No progress percentage without an explicit product contract and evidence basis.
- No pronunciation judgment from ASR text alone.
- Test result, homework completion, attendance logistics and portal access are distinct from learning evidence.
- Supported retrieval must not be relabeled independent mastery.
- Family-facing language must remain readable and must not expose internal pipeline terminology.

## 8. Regeneration rule

A Portfolio may be regenerated from verified source/canonical evidence to comply with a newer presentation contract.

Regeneration MUST:
- preserve all valid historical Class Reports;
- preserve lesson dates and source lineage;
- preserve longitudinal claims only when supported;
- not invent missing evidence;
- not silently remove valid vocabulary, grammar or corrections;
- identify the new presentation version.

## 9. Frozen decision

Effective 18 September 2026:

> A PRIME Family Edition Portfolio is a standardized longitudinal learning report, not an accumulation of differently shaped lesson summaries. Every edition must include an immediate Family Executive Summary, stable cumulative learning sections, and a complete Class Report for every attended persisted lesson under the frozen Class Report schema.
