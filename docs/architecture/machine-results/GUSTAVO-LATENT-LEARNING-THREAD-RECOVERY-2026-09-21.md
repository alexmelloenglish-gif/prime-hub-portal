## New machine capability

**Latent Learning Thread Recovery**

Definition:
A latent learning thread is a historically evidenced pedagogical line that:
1. occurred in the authorized lesson history;
2. was not sufficiently resolved or independently verified;
3. remains pedagogically relevant;
4. may no longer be foregrounded in the current projection;
5. can be surfaced as a candidate for future verification without being promoted to learner state.

The machine may remember a pedagogically relevant thread that the current human/product projection has stopped foregrounding. It may surface that thread; it may not convert it into fact, deficit, mastery or mandatory plan without the required authority.

## Cross-executor divergence taxonomy

### Class A — factual / structural divergence
Executors disagree about lesson identity, source event, chronology, speaker, support condition or other evidence-bearing fact.
Requires reconciliation before downstream authority.

### Class B1 — interpretation/state divergence
Executors use different pedagogical interpretations or state compression for substantially the same evidence.
Example: RECENT vs DEVELOPING.
Requires evidence-bound reconciliation and teacher authority where consequential.

### Class B2 — latent-thread recovery divergence
One executor surfaces an evidence-backed unresolved/reconnectable pedagogical thread that another executor did not foreground.
Example: spelling, should/shouldn't, weekly routine/calendar.

B2 is **not an error merely because another executor omitted the thread**.
It is useful machine divergence when:
- provenance is identifiable;
- the claim boundary is preserved;
- it remains candidate/verification/planning material;
- it does not silently alter canonical learner state.

### Class C — semantically equivalent expression
Different wording/presentation with materially equivalent evidence and pedagogical meaning.

## Invariants

1. Omission by one executor does not invalidate a supported latent thread found by another.
2. Recovery by one executor does not automatically make the thread a canonical priority.
3. A latent thread must point back to authorized evidence/provenance.
4. Observation debt is not learner deficit.
5. Reconnection is not automatically progress.
6. Planning candidates are not performed history.
7. The teacher decides whether a surfaced thread becomes an instructional priority.
8. Executor diversity is useful when it increases evidence recall without weakening authority boundaries.

## Machine-level implication

Portability does **not** mean every executor must produce an identical shortlist.

The target is:
- shared factual/evidentiary core;
- compatible claim boundaries;
- preserved uncertainty;
- transparent provenance;
- bounded useful divergence.

A stronger machine can therefore be both reproducible and generative:
it reconstructs the same learning history while allowing different executors to recover different legitimate pedagogical opportunities from that history.
