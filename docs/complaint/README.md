# Dossiê de reclamação — Perplexity

Este diretório reúne a documentação de suporte à reclamação formal sobre a prestação do serviço Perplexity Pro / Perplexity Computer.

## Conteúdo

| Arquivo | Descrição |
|---|---|
| `RELATORIO_FINAL_CONSOLIDADO.md` | Relatório consolidado das falhas |
| `FALHAS_CONSOLIDADAS_PTBR.csv` | Matriz de 14 falhas |
| `PROMESSAS_NAO_CUMPRIDAS_PTBR.csv` | 10 promessas e status |
| `FALHAS_DE_IDIOMA_PTBR.csv` | Registro das falhas de idioma |
| `LINHA_DO_TEMPO_EXECUCAO.csv` | Linha do tempo de 27 eventos |
| `SOLICITACAO_SUPORTE_PERPLEXITY.md` | Solicitação formal ao suporte |

## Como usar

1. Leia o `RELATORIO_FINAL_CONSOLIDADO.md` para entender o panorama.
2. Consulte os CSVs para evidências detalhadas.
3. Use `SOLICITACAO_SUPORTE_PERPLEXITY.md` como base para contato com o suporte.
4. Preencha o campo `[TASK_URL_TO_BE_INSERTED]` com o URL real da tarefa antes de enviar.
